# Feedback & Learnings

Discovered preferences, approaches that work/don't work, and optimizations learned through experience.

## File Organization

- **[coding-style.md](coding-style.md)** — Discovered coding preferences
- **[approach.md](approach.md)** — What works and what doesn't
- **[performance.md](performance.md)** — Optimization learnings

## Usage

These files accumulate feedback over time. They inform:
- Code review guidelines
- Design decisions
- Tool selections
- Process improvements

## Format

```markdown
---
name: feedback-topic
description: What was learned
metadata:
  type: feedback
  updated: 2025-09-13
---

## Rule / Observation

### What Works
- Description with evidence

### What Doesn't Work
- Description with examples

### Why
- Root cause analysis

### How to Apply
- Action to take based on learning

### Related
- Links to KB standards or other feedback
```
