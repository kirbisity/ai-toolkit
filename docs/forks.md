# Forked Skills

Open-source skills adapted into this plugin. Policy (ADR-009):
- Route to installed skills first, and fork only when one must change to fit at-sdlc.
- A fork lives at `skills/at-<name>/`, with an `UPSTREAM.md` giving the source
  repo, commit, licence and what changed.
- Permissive licences only: MIT, Apache-2.0, BSD.
- To refresh a fork, diff its upstream from the commit below and re-apply the changes.
